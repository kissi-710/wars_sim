# 未決・曖昧事項 (v0.7)

`spec.md` の【暫定】と対応。**★ = 仕様の骨格・バランスに影響するので先に決めたいもの**。
「暫定案」は回答が無ければそのまま採用する。

## 決定済み(v0.2〜v0.3 で反映)

| 内容 | 決定 |
|---|---|
| 民間人は戦えるか | 戦える。攻撃力はかなり低い(暫定値 1) |
| 建物を壊す/奪う手段 | **占領**。建物の半径 2 マスの領土を敵に奪われると占領される(建物に HP は無し) |
| 村の役割 | 初期領土の核。**無条件で人を生産**(住居より効率は悪い)。領土・資源でレベルアップ(村→街→都市)= 文明レベル |
| 文明レベルの効果 | 各種生産効率・装備の質に影響 |
| 建物の入手 | デフォルト配置 + 国が勝手に建設。後者は **個数制限** あり |
| 生産効率 | 建物の周囲 8 マスにいる人の数で決まる。**16 人で最大 200%** |
| 目標軍人比率 | 国の **性格** で決まる。好戦的な国は積極的に軍人を作る |
| 平和的な国の生存策(v0.3) | ①軍人にだけ食料の維持費 ②平和的な国は装備を大量に備蓄し、敵が自国領に来たら総動員して一気に軍人化 ③自国領内では攻撃力に防衛補正 |
| 食料消費の対象(v0.3) | **当面は軍人のみ**。民間人は消費しない |
| 膠着への対応(v0.6) | 軍人の攻撃範囲を「自分のマス + 上下左右」に(満員マスにも隣から攻撃)。**建物の個数上限は領土に比例し、領土が減っても下がらない**。AI を強化(国の戦略・撤退・集中攻撃・警戒線・経済の必要度判断) |
| 実装(v0.5) | Phase 0〜6 を実装。バランス検証で軍人比率(好戦的 30/45%・中庸 20/35%・平和的 8/25%)、工房(6 ターン・食料 1 + 鉱物 2)、開拓者の割合(50%)を調整。結果は spec §15.1 |

## ★ 決定済みルールの詳細(具体値・境界を詰めたい)

| # | 論点 | 暫定案 |
|---|---|---|
| ★Q1 | **占領の判定**。「半径 2 マス」= 5×5(チェビシェフ距離)か、ひし形(マンハッタン距離)か。「奪われる」= 全マスか、過半数か、1 マスでも? 占領時に進捗はどうなる? | 5×5 のうち建物自身を除く 24 マス。1 つの敵国が **過半数(13 マス以上)** を領有で占領。進捗リセット。連鎖は次ターン |
| ★Q2 | **村まわり**: 村は 1 国に 1 つだけ? 占領した村はどうなる? 村を奪われた国は滅亡? | 占領した村は占領国の村になる(複数所持可)。滅亡は「村 0 個 かつ ユニット 0 体」 |
| ★Q3 | **効率式**。「16 人で 200%」だが 0 人のときは? 数える「人」は自国の民間人だけ? 二重計上は? | `100% + 人数/16 × 100%`(0 人で 100%、16 人で 200%)。自国の民間人のみ。1 人が複数建物に数えられる。稼働条件の「充分な民間人」は別途、最低 2 人(住居・村は 0 人) |
| ★Q4 | **文明レベル**: 国単位か村単位か。レベルの判定基準(領土 × 資源の閾値、在庫か累計産出か)。降格するか。装備の質の反映(装備時に固定か、後で強化されるか)。段階数 | 国単位・3 段階(村/街/都市)。領土 **かつ** 食料在庫 **かつ** 鉱物在庫が閾値以上で上昇。降格なし。装備の攻撃力は装備時点で固定(6/9/13)。効率 ×1.0/1.25/1.5 |
| ★Q5 | **国の性格**: 種類と、軍人比率以外への影響(侵攻の積極性、建設の偏り) | 3 種(好戦的 50% / 中庸 25% / 平和的 10%)。攻撃性と建設の重みも性格で決まる。開始時にシードから割り当て・固定 |
| ★Q29 | **v0.3 の追加ルールの具体値**(v0.5: 検証済み・一部調整。spec §15.1)(維持費・総動員・防衛補正)。特に: 維持費の値と飢餓の処理、総動員の発動条件(敵軍人が自国領にいる)と解除までの猶予、防衛補正の倍率、性格ごとの備蓄上限 | 維持費は軍人 1 体 毎ターン食料 0.05、不足した軍人は毎ターン HP-1。総動員は「自国領に敵軍人がいる/建物を占領された」で発動し、いなくなって 20 ターンで解除、1 ターン 10 体まで軍人化(平時は 2 体)。防衛補正は自国領で ×1.25。備蓄上限は好戦 5 / 中庸 12 / 平和 30。これらは `scripts/balance.ts`(spec §15)で勝率を見て調整する前提の仮値 |
| ★Q6 | **個数制限**: 種類ごとか全体か。数値。デフォルト建物は数に含めるか。デフォルト建物の内訳 | 種類ごと(表は spec §6.3、レベルで増加)。初期・占領で得た建物も数に含む(占領での超過は可)。デフォルトは 村1・畑1・鉱山1・住居1 |

## v0.6 で暫定のまま決めたこと

| # | 論点 | 暫定案 |
|---|---|---|
| ★Q39 | **人口の上限**(民間人が増え続けてマスを埋め、軍人が入れなくなるのを防ぐ) | 上限 = max(24, 領土 × 0.5)。達すると住居・村は生産を止める。民間人にも食料の維持費をかける案もある(今は軍人のみ) |
| Q40 | **建物の個数上限**の式(領土に比例・下がらない) | 上限 = 基本数 + floor(最大領土 / 面積あたり)。住居・畑は 30 マスにつき 1、鉱山 50、工房 100。文明レベルによる上限倍率は廃止 |
| Q41 | 満員のマスへの**入れ替え**(軍人のみ。友軍の民間人と交代) | 軍人だけ。民間人どうし・軍人どうしは入れ替えない |
| Q42 | 軍人の攻撃範囲(自分のマス + 上下左右)。民間人は同じマスのみ。攻撃対象は敵軍人優先・残り HP が少ない敵を集中攻撃 | spec §8 の通り。攻撃範囲を広げる(2 マス)案や、遠距離兵種は将来の拡張 |
| Q43 | 国の**戦略**(攻撃目標の選び方・侵攻のしきい値・首狩り) と、性格ごとの補正(好戦的の攻撃 ×1.3、平和的の内政 ×1.1・攻撃 ×1.2・備蓄 80) | spec §7.3・§6.1 の通り。バランス検証(§15.1)で決定。決着を早めたいならしきい値を調整 |

## v0.7 で暫定のまま決めたこと(「決着がつかない」問題の対策。spec §15.3)

| # | 論点 | 暫定案 |
|---|---|---|
| ★Q44 | 建物を失った国の残党を、誰がどう狙うか(建物が無いと攻撃目標が定まらない問題) | 相手の建物→無ければ残存領土→それも無ければユニットの現在地、の順に直接の攻撃目標にする(spec §7.3) |
| ★Q45 | 建物の建設で、敵味方問わずマスを完全に取り囲んでしまう(閉じ込め)のを防ぐか | 防ぐ。建設時に、隣接するどのマスも 4 方向すべて建物で塞がる配置は避ける(spec §6.3)。斜め方向からの囲い込みなど、他の閉じ込め方までは対策していない |
| ★Q46 | 互角の相手同士がいつまでも開戦しない「膠着」への対策(戦争疲れの具体値) | 国境を接した相手がいるのに開戦を見送るたびに、しきい値が 0.01 ずつ下がる(下限 0.5)。開戦すると 0 にリセット(spec §7.3)。値はバランス検証で調整する前提の仮値 |
| Q47 | **孤立崩壊**: 建物を全く持たない国(生産手段が無い)をどう扱うか | 建物 0 が 150 ターン続くと、全ユニットが毎ターン HP 0.25 ずつ弱って消滅する(spec §7.4)。猶予期間・減衰速度は仮値。民間人だけの平和な小国が、たまたま一時的に建物 0 になった場合に不当に死なないよう、猶予期間を長めに取っている |
