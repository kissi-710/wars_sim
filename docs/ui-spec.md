# wars_sim 画面UI仕様書 (ドラフト v0.1)

`spec.md` §11 の詳細版。ゲームの中身は [spec.md](spec.md)、未決事項は [open-questions.md](open-questions.md)(UI 関連は Q30〜)。

> 凡例: **【確定】** 依頼で明示 / **【暫定】** 仮の案(数値・挙動は調整前提)

## 1. 要件

- 【確定】画面は次の 4 要素で構成する: **① シミュレートしているマップ画面 / ② ログ / ③ マスの詳細情報 / ④ 国ごとの詳細情報**
- 【確定】マップ画面は **自由度高く動かせる**(ズーム・スクロール(パン)など)
- ゲームは「眺める」ものなので、**見ていて状況が分かる**(何が起きたか・どこで起きたか・なぜそうなったか)ことを最優先にする。

## 3. マップ画面 (MapView / MapToolbar / Minimap)

### 3.1 ビュー変換

```ts
interface Viewport {
  scale: number   // 1 マスあたりの CSS px(ズーム)
  cx: number      // 画面中央に来るワールド座標 x(マス単位・小数可)
  cy: number
}
// screen = (world - center) * scale + viewSize / 2
```

- 座標変換 (`worldToScreen` / `screenToWorld` / `zoomAt` / `clampViewport`) は **純粋関数** にして `src/render/viewport.ts` に置く(Vitest でテスト可能)。
- ワールドは 100×100 マス(座標 0〜99)。

### 3.2 ズーム 【確定+暫定 Q31】

| 操作 | 動作 |
|---|---|
| マウスホイール | **カーソル位置を固定点として**ズーム(滑らか。`factor = 1.0015 ** -deltaY`) |
| ピンチ(タッチ/トラックパッド) | 2 本指の中心を固定点としてズーム |
| `＋` `－` ボタン / キー `+` `-` | 画面中央を固定点に ×1.25 / ÷1.25(120ms のイージングアニメ) |
| `全体` ボタン / キー `0` / `Home` | マップ全体が収まるスケールで中央へ(アニメ) |
| ダブルクリック | そのマスを中心に一段ズームイン(`Shift`+ダブルクリックでズームアウト) |

- スケール範囲: **最小 = 全体表示の 60%**(マップが小さく中央に浮く)/ **最大 = 80 px/マス**。
- 画面解像度に依らず 1 マス = 整数 px になるよう、静止時はスケールを丸めない(拡大時のにじみは `imageSmoothingEnabled = false` で回避)。

### 3.3 スクロール(パン) 【確定+暫定 Q31】

| 操作 | 動作 |
|---|---|
| 左ドラッグ(4px 以上動いたらドラッグ、それ未満はクリック扱い) | 移動 |
| 中ボタン / `Space`+ドラッグ | 移動(ドラッグ中はカーソルが「掴む」) |
| 矢印キー / `WASD` | 移動(`Shift` で高速) |
| ホイール横スクロール / トラックパッド 2 本指 | 移動(`Ctrl`+ホイールでズーム) |
| タッチ 1 本指 | 移動 |
| ミニマップをクリック/ドラッグ | その位置へ移動 |
| 慣性 | ドラッグを離した後、少し滑って止まる(ON/OFF は設定) |

- 移動範囲(クランプ): **マップのどのマスも画面中央に置ける**まで(マップの外側は余白として表示)。「端まで見たいのに動かない」を避ける。

### 3.4 選択・ホバー

- **クリック** = マスを選択(黄枠)→ マス詳細(§4)。選択中の建物があれば、その **占領判定範囲(半径 2)** と **作業範囲(周囲 8 マス)** を重ねて表示(§3.6)。
- **ホバー** = 白い細枠 + **ステータスバー** に要約(座標 / 領有国 / 建物 / ユニット数)。ツールチップではなく画面下端の固定バーにする(描画コストが小さく、隠れない)。
- `Esc` で選択解除。選択はターンが進んでも **マス(座標)に固定**。
- 国カードにホバー → その国の領土をマップ上で明るく、他を減光(**国ハイライト**)。国を選択すると固定。

### 3.5 追従(フォロー)

- マス詳細のユニット行の `追従` → カメラがそのユニットを追いかける(ユニットが消滅したら停止しログに通知)。
- 国カードの `村へ移動` → その国の村(拠点)へカメラ移動。
- **オートカメラ**(観戦モード): カメラが自動で「戦闘」「占領」「滅亡」などの見どころへ移動する。既定は OFF。 【暫定 Q32】

### 3.6 レイヤー(表示切替)

`レイヤー▾` メニューでチェックボックス。設定は localStorage に保存(読み書きは try/catch。失敗しても動く)。

| レイヤー | 既定 | 内容 |
|---|---|---|
| 領土 | ON | 領有国の色で塗る(無所有は暗灰) |
| 国境線 | ON | 異なる国どうしの境に線 |
| グリッド | 自動 | スケール ≥ 12 px のとき薄く表示 |
| 建物 | ON | 種別アイコン。村は 村/街/都市 で見た目が変わる |
| ユニット | ON | 民間人 = 丸、軍人 = 四角(国色) |
| 戦闘マーカー | ON | このターンに攻撃・被弾があったマスを赤く点滅。拡大時は攻撃線(誰が誰を撃ったか)も描く |
| 国名ラベル | ON(縮小時) | ズームアウト時、領土の重心に国名 |
| ヒートマップ | なし | `なし` / `民間人密度` / `軍人密度` / `生産効率` |
| 占領判定範囲 | ON | 選択した建物の半径 2 マス(24 マス)と、各敵国の領有数を色分け |
| 作業範囲 | ON | 選択した建物の周囲 8 マス |

### 3.6.1 スケールに応じた描画の詳細度(LOD)【暫定】

| スケール(px/マス) | 描画 |
|---|---|
| < 3 | 領土色 + 建物を 1 点で。ユニットは非表示(国名ラベルを表示) |
| 3 〜 8 | + 建物を色矩形で。ユニットは「マスにいる/いない」を 1 点で |
| 8 〜 20 | + ユニットを 2×2 の個別ドットで。グリッド線、戦闘マーカー |
| 20 〜 48 | + 建物アイコン(種別・レベル)、ユニットの種別形状、HP バー、生産進捗リング |
| ≥ 48 | + 攻撃エフェクト(ヒット)、占領時のエフェクト、数値(HP など) |

### 3.7 描画方式 【暫定】

- **Canvas 2D**、`devicePixelRatio` 対応、`ResizeObserver` でリサイズ追従。
- **領土レイヤーは 100×100 のオフスクリーン Canvas(1 マス = 1px)** に持ち、**変化したマスだけ更新**して、ビュー変換で拡大描画する(最近傍補間)。
- 建物・ユニットは **画面内に見えるマスだけ**走査して描画(カリング)。
- `requestAnimationFrame` は、**ビューが動いている/シミュレーションが進んでいる/エフェクト中**のときだけ回す。完全に静止していたら止める。
- 高速再生(MAX)でも、1 フレームで描画するのは最新状態の 1 回だけ。
- ユニットの移動は、ゆっくり再生(1x)のとき **前のマスから次のマスへ補間** して滑らかに見せる(速度が上がると補間を切る)。 【暫定 Q33】

### 3.8 ミニマップ

- マップ右下に 100×100 を 1 マス = 1〜2 px で表示。領土色のみ(建物・ユニットは出さない)。
- 現在のビューを矩形で表示。クリック/ドラッグでカメラ移動。ON/OFF 切替可。
- 領土レイヤーのオフスクリーン Canvas を流用するので追加コストはほぼ無い。

## 4. マスの詳細情報 (CellInspector) 【確定+暫定】

選択したマスの、その時点の状態を表示(ターンごとに更新。表示更新は 5 Hz 程度に間引く)。

**共通**
- 座標 `(x, y)`
- 領有国(色・国名)/ 無所有
- そのマスの直近ログ(最大 5 件。クリックでログへジャンプ)

**建物があるとき**
- 種別・所有国・(村なら)文明レベル名(村/街/都市)
- **稼働状況**: 稼働中 / 停止中(理由: 食料不足 / 鉱物不足 / 周囲の民間人不足 / 備蓄上限 / 出現先が無い)
- **生産効率の内訳**: `周囲の自国民間人 n/16 → 人数効率 1.xx × 文明補正 1.xx = 最終 x.xx`
- 進捗バー(次の生産までの進捗)
- **占領状況**: 半径 2 マス(24 マス)内の領有数を国ごとに表示。例 `A国 18 / B国 4 / 無所有 2`、占領ライン 13 を超えていれば警告色
- 「占領範囲/作業範囲を地図に表示」チェック

**ユニットがいるとき(最大 4 体)**
- 各行: 種別(民間人/軍人)・国・HP(バー + 数値)・攻撃力・状態(移動中/戦闘中/作業中/飢餓)・`追従` ボタン

**戦闘中のとき**
- 参加国ごとの体数と合計 HP、防衛補正の有無(自国領か)。同じマスに敵がいなくても、直近のターンに攻撃・被弾があれば「戦闘があったマス」と表示(軍人は隣接 4 マスにも攻撃できる)

## 5. 国ごとの詳細情報 (CountryList / CountryDetail) 【確定+暫定】

### 5.1 国一覧(国タブの上部)

各国 1 カード(全国を 1 画面に収める。最大 8 国):

- 色チップ・国名・性格アイコン・文明レベル名・状態バッジ(`総動員中` / `滅亡`)
- 数値: 領土マス数、民間人、軍人(比率 / 目標比率)、食料・鉱物・装備
- **領土シェアバー**(全マス数に対する各国の割合を 1 本の積み上げバーで表示)
- クリックで詳細を開く / ホバーで国ハイライト / `村へ移動`

### 5.2 国の詳細(選択した国)

| セクション | 内容 |
|---|---|
| 概要 | 性格(攻撃性・目標軍人比率・総動員時比率・備蓄上限)、文明レベル、村の位置(クリックで移動) |
| 文明レベル | 次レベルまでの進捗バー 3 本(領土 / 食料 / 鉱物)。現在の効果(効率補正・装備攻撃力) |
| 人口 | 民間人数・軍人数・軍人比率 vs 目標比率のゲージ |
| 人口・戦略 | 人口 / 人口上限(領土 × 0.5)、現在の構え(侵攻 / 防衛 / 平時)と攻撃目標(首狩り中かどうか) |
| 資源 | 食料・鉱物・装備の在庫と **毎ターン収支**(生産 − 軍人の維持費)。装備は備蓄上限も表示。食料収支が赤字なら警告 |
| 建物 | 種別ごとの数 / 個数上限(最大領土に比例し、領土が減っても下がらない。占領で上限超過もあり得る) |
| 戦績 | 撃破数・戦死数(民間人/軍人別)・占領した建物数・奪われた建物数・飢餓による損失 |
| 推移グラフ | 領土 / 人口 / 軍人 / 食料 / 鉱物 の時系列(折れ線)。系列の切替チェック |

### 5.3 全体比較

国タブ最上部に、**領土シェアの推移(積み上げ面グラフ)** を常時表示。誰が伸びて誰が縮んでいるか一目で分かる。

### 5.4 推移データ 【暫定 Q34】

- コアが **10 ターンごと**に国ごとの統計を 1 サンプル記録(リングバッファ、最大 1,000 サンプル = 10,000 ターン分。超えたら間引いて長期間を保持)。
- グラフは SVG(または小さな Canvas)で自前描画。外部チャートライブラリは入れない。

## 6. ログ (LogPanel) 【確定+暫定 Q35】

下部ドロワー。**何が起きたかを時系列で追える**、かつ **クリックで該当マスに飛べる**。

### 6.1 行の形式

```
T1234  ●A国  (42,17)  B国に建物「畑」を占領された           ← クリックで (42,17) へ移動+ピン表示
```

- ターン番号 / 国の色ドット / 座標 / 文。座標クリック → カメラ移動して該当マスを選択、マップ上に **波紋エフェクト(ping)**。
- 国が複数関わる行は、関係国の色ドットを並べる。

### 6.2 イベントの種類と重要度

コアは **構造化イベント** を出力し、UI が文言に整形する(コアは Vue・文言に依存しない)。

| 種類 | 例 | 重要度 |
|---|---|---|
| 勝利 / 国の滅亡 | 「B国が滅亡した」「A国の勝利」 | 重大 |
| 建物の占領 | 「A国が B国の畑を占領」(**村は重大**、他は通常) | 重大/通常 |
| 文明レベルアップ | 「A国が『街』になった」 | 重大 |
| 総動員の開始/解除 | 「C国が総動員を発令」 | 通常 |
| 交戦開始(初めて接触した国どうし) | 「A国と B国が初めて交戦」 | 通常 |
| 侵攻の開始(攻撃目標を決めた) | 「A国が B国への侵攻を開始」(相手が弱ければ「村を狙って…(首狩り)」) | 通常 |
| 戦闘(まとめ行) | 「(30,40) で A国 vs B国 の戦闘が決着。損害 A:3 B:5」 | 損害が大きければ通常、他は詳細 |
| 建設 | 「A国が鉱山を建設」 | 通常 |
| 飢餓 | 「A国の軍人が飢餓状態(食料不足)」 | 通常(発生時 1 回)/ 詳細 |
| 軍人化 | 「A国で 5 体が軍人化」 | 詳細(まとめて 1 行) |
| 人口の節目 | 「A国の人口が 100 に」 | 詳細 |

- **連続する戦闘は 1 件に集約する**(同じマス・同じ国の組で戦闘が続いている間は 1 行を更新し、決着時に確定)。毎ターン 1 ユニットごとの行は出さない。
- 軍人化・建設なども **同一ターン・同一国はまとめる**。

### 6.3 表示機能

- **フィルタ**: 重要度(`重大のみ` / `通常以上` / `すべて`)、種類(チップの ON/OFF)、国(色チップの ON/OFF)、テキスト検索。
- **自動追尾**: 最新行へ自動スクロール(ON/OFF。手動でスクロールを上げたら自動で OFF、末尾に戻ったら ON)。
- **仮想スクロール**(表示行だけ描画)で数千件でも軽く。
- 保持件数: 最大 5,000 件(リングバッファ)。古い「詳細」から先に捨てる。 【暫定 Q35】
- 重大イベントは画面右上に **トースト**(3 秒)も出す(ON/OFF 可)。

## 7. コントロールバー (ControlBar)

| 要素 | 動作 |
|---|---|
| ▶/⏸ | 再生/一時停止(`Space`) |
| ⏭ | 1 ターン進める(一時停止中。`.`) |
| 速度 | `1x 2x 5x 10x MAX`(§spec 11.4 と同じ)。`[` `]` で増減 |
| ⟲ 新規 | **新規ゲームダイアログ**: シード(空欄=ランダム)、国数(2〜8)、性格(ランダム/国ごとに指定)。`同じシードで最初から` ボタンも |

| 性能表示 | 描画 fps / 実効 tps(小さく) |
| ⚙ 設定 | 慣性・トースト・補間・ミニマップ・テーマ等のトグル |
| ? ヘルプ | 操作(ショートカット)一覧のダイアログ |

### ショートカット一覧

`Space` 再生/停止 / `.` 1 ターン / `[` `]` 速度 / `+` `-` ズーム / `0` `Home` 全体表示 / 矢印・`WASD` 移動 / `1`〜`8` 国 1〜8 の村へ移動 / `F` 追従 ON/OFF / `G` グリッド / `M` ミニマップ / `L` ログ開閉 / `Tab` サイドバー タブ切替 / `Esc` 選択解除

## 8. コンポーネントと状態管理

### 8.1 コンポーネント

```
App.vue
├─ ControlBar.vue
├─ MapArea.vue
│   ├─ MapToolbar.vue        ズーム・全体・レイヤー・追従
│   ├─ MapView.vue           Canvas + ポインタ/キー操作 + ping/エフェクト
│   ├─ MapMinimap.vue
│   └─ MapStatusBar.vue
├─ SideBar.vue               タブ: 国 / マス
│   ├─ CountryList.vue       カード一覧 + 領土シェア推移
│   ├─ CountryDetail.vue     詳細(セクション + 推移グラフ)
│   ├─ CellInspector.vue
│   └─ charts/ LineChart.vue, StackedAreaChart.vue, StatBar.vue
├─ LogPanel.vue              下部ドロワー(仮想スクロール + フィルタ)
├─ ToastHost.vue
└─ dialogs/ NewGameDialog.vue, HelpDialog.vue, SettingsDialog.vue
```

### 8.2 composables / モジュール

| 名前 | 役割 |
|---|---|
| `render/viewport.ts` | ビュー変換の純粋関数(ズーム・パン・クランプ) |
| `render/mapRenderer.ts` | Canvas 描画(領土オフスクリーン・LOD・カリング・エフェクト) |
| `composables/useSimulation.ts` | ループ・速度・1 ターン送り |
| `composables/useViewport.ts` | ポインタ/キー/ホイール入力 → Viewport 更新・アニメーション |
| `composables/useSelection.ts` | 選択中のマス/国/追従対象、国ハイライト |
| `composables/useLog.ts` | イベント → 表示行への整形、フィルタ、集約 |
| `composables/useUiPrefs.ts` | レイヤー・パネル幅・設定の保存(localStorage、try/catch) |

- 状態管理は **Pinia を使わず**、`reactive`/`ref` を使った小さなモジュール(`provide/inject` または module 単位のシングルトン)にする。UI 状態は少ないため。 【暫定 Q36】
- **ワールド状態は Vue のリアクティブにしない**(`markRaw`)。UI は `version`(tick カウンタ)を購読し、**パネルの更新は 5 Hz 程度に間引く**。マップの描画は 60fps。

### 8.3 コア側が UI 向けに提供するもの(spec への追加)

```ts
// src/core/events.ts
type SimEvent = {
  turn: number
  type: 'occupy' | 'levelUp' | 'mobilize' | 'demobilize' | 'contact' | 'battle'
      | 'build' | 'starve' | 'convert' | 'extinct' | 'victory' | 'milestone'
  importance: 'major' | 'normal' | 'minor'
  countries: number[]          // 関係国(主体, 相手)
  pos?: { x: number; y: number }
  data: Record<string, number | string>   // 損害数・建物種別 など
}

// src/core/stats.ts  国ごとの時系列サンプル(10 ターンごと)
type CountrySample = { turn: number; land: number; civilians: number; soldiers: number
                       food: number; ore: number; equipment: number }
```

- 集約(戦闘のまとめ行など)は **コア側で確定したイベント** として出す(UI 側で組み立てない)。同じイベント列は `scripts/balance.ts`(バランス検証)でも使える。
- 戦績(撃破数・占領数など)は国ごとの累計カウンタとして持つ。

## 11. ビジュアルデザイン(v0.2 で追加)

- **配色**: 青みのあるダークスレートを基調にし、UI のアクセントは青と金に絞る。国色(赤・青・緑・黄・紫・水色・ピンク・橙)が最も目立つようにするため、UI 側は彩度を抑える。色は CSS 変数(`src/style.css` の `:root`)に集約。
- **ヘッダー**: ロゴ(4 国色の 2×2)+ 再生/1 ターン/速度(セグメント)+ ターン数のピル(進行中は点滅)+ シード・fps のピル。アイコンは自前の線画 SVG(`Icon.vue`、外部ライブラリなし)。
- **地図**:
  - 領土は国色を落ち着かせて塗り、市松の微かな明暗で質感を出す。背景はラジアルグラデーション、盤面に影、四隅にビネット。
  - **国境は「各国の領土の内側」に国色の明るい線**で縁取る(隣り合う国が 2 色の縁取りになる)。
  - 建物は丸みのあるタイル(上が明るいグラデーション + 国色の縁 + 影)。村は一回り大きく、レベルを点で示す。稼働状況(停止・人口上限・備蓄上限)は右上の点で示す。
  - ユニットは、民間人 = 明るい丸、軍人 = 濃い角丸の四角 + 白縁(拡大時は影と兜の帯)。
  - 戦闘マーカーは赤い発光、攻撃線はオレンジ。選択マスは金色の二重枠。国名ラベルは国色の点つきのピル。
- **サイドバー**: 国カードは左に国色の帯、性格・レベル・状態のタグ、数値のスタット表示、民間人 / 軍人の比率バー。国の詳細は角丸のカード(セクション)に分ける。
- **ログ**: 重要度を左の帯で示す(重大 = 金 + グラデーション、通常 = 青)。種類は色分けしたタグ(戦闘 = 赤、占領 = 橙、建設 = 青、文明 = 金、総動員 = 赤、国家 = 紫、飢餓 = 黄)。
- **グラフ**: 折れ線の下にグラデーションの塗り。3 本の補助線。
- **ダイアログ・メニュー・トースト**: 背景ぼかし(backdrop-filter)、影、出現アニメーション。
